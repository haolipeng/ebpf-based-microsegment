# Task: 修复拓扑数据 LABEL 视图实时更新缺失

## 关联

- **Epic**: network-topology-improvements
- **PRD**: network-topology-data-foundation-fix

## 目标

补充 `mergeTopologyUpdate` 函数缺失的 LABEL 视图实时更新逻辑,确保 LABEL 视图模式下的 WebSocket 实时数据能正确合并到拓扑数据中。

## 技术细节

### 问题描述

`web/src/utils/topologyUtils.ts` 中的 `mergeTopologyUpdate` 函数只实现了 IP 视图的实时更新逻辑,缺少 LABEL 视图的处理分支,导致:
- LABEL 视图模式下实时流数据无法正确更新
- 服务级别的节点和边无法动态增量更新

### 解决方案

在 `mergeTopologyUpdate` 函数中添加 LABEL 视图处理逻辑:

1. 提取源和目标服务标签
2. 跳过没有标签的流
3. 创建/更新 SERVICE 类型节点
4. 更新节点指标(流量计数、包计数、字节计数、活跃流)
5. 创建/更新边,包含协议和方向信息

### 实现位置

- 文件: `web/src/utils/topologyUtils.ts`
- 位置: 第 474-567 行(共 94 行新增代码)
