# Task: Design TCP State Machine Architecture

## Description
Design the architecture for a complete RFC 793-compliant TCP state machine to be used in eBPF programs. This includes defining the state enumeration, planning transition functions, and determining integration points with existing TC and XDP programs.

## Acceptance Criteria
- [x] TCP state enumeration defined (all 11 states)
- [x] State transition logic designed (inbound/outbound)
- [x] Integration approach planned (header-only design)
- [x] Performance considerations documented

## Technical Details

**State Enumeration** (already exists in common_types.h):
- TCP_STATE_CLOSED
- TCP_STATE_SYN_SENT, SYN_RECV
- TCP_STATE_ESTABLISHED
- TCP_STATE_FIN_WAIT1, FIN_WAIT2
- TCP_STATE_CLOSE_WAIT, CLOSING
- TCP_STATE_LAST_ACK, TIME_WAIT

**Design Decisions**:
1. Header-only implementation for reusability
2. Separate inbound/outbound transition functions
3. Integration in hot path with minimal overhead
4. Backward compatibility (no Map changes)

**Files Affected**:
- `src/bpf/headers/tcp_state_machine.h` (new file)
- `src/bpf/headers/common_types.h` (reference only)
