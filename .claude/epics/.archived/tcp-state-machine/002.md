# Task: Implement TCP State Machine Header File

## Description
Create `tcp_state_machine.h` with all helper functions for TCP state tracking. This includes flag extraction, state transition logic for both inbound and outbound packets, and utility functions for state checking.

## Technical Details

**Core Functions**:
```c
// Extract TCP flags from tcphdr
static __always_inline __u8 get_tcp_flags(struct tcphdr *tcph)

// Handle inbound packet transitions (server perspective)
static __always_inline __u8 tcp_state_transition_inbound(__u8 current, __u8 flags)

// Handle outbound packet transitions (client perspective)
static __always_inline __u8 tcp_state_transition_outbound(__u8 current, __u8 flags)

// Check if connection is closing
static __always_inline bool is_tcp_state_closing(__u8 tcp_state)

// Check if connection is established
static __always_inline bool is_tcp_state_established(__u8 tcp_state)
```

**State Transitions Covered**:
- Three-way handshake (client and server)
- Active close (FIN_WAIT1 → FIN_WAIT2 → TIME_WAIT)
- Passive close (CLOSE_WAIT → LAST_ACK → CLOSED)
- Simultaneous close (CLOSING → TIME_WAIT)
- RST handling (ANY → CLOSED)
