# Task: Integrate TCP State Machine with TC Program

## Description
Integrate the TCP state machine into the Traffic Control (TC) eBPF program. This includes creating a state update function, modifying session creation to extract TCP flags, and updating the hot path to track state transitions.

## Acceptance Criteria
- [x] `update_tcp_state()` function added to TC program
- [x] `create_session()` modified to accept skb parameter
- [x] Hot path updated to call state machine (protocol gating)
- [x] New sessions initialized with correct TCP state
- [x] State-based closing detection implemented
- [x] No performance regression

## Technical Details

**Changes to tc_microsegment.bpf.c**:

1. **Include header**:
```c
#include "headers/tcp_state_machine.h"
```

2. **New function**:
```c
static __always_inline __u8 update_tcp_state(
    struct __sk_buff *skb,
    struct flow_key *key,
    __u8 current_state)
```

3. **Modified create_session()**:
- Add `struct __sk_buff *skb` parameter
- Extract TCP flags for initial state
- Initialize `tcp_state` field correctly

4. **Hot path update**:
```c
if (key.protocol == IPPROTO_TCP) {
    __u8 old_tcp_state = session->tcp_state;
    session->tcp_state = update_tcp_state(skb, &key, old_tcp_state);

    if (is_tcp_state_closing(session->tcp_state) && ...)
        session->state = SESSION_STATE_CLOSING;
}
```
