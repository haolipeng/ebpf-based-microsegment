## Technical Details

**Test Scenarios**:

1. **Three-Way Handshake**:
   - Client: CLOSED → SYN_SENT → ESTABLISHED
   - Server: CLOSED → SYN_RECV → ESTABLISHED

2. **Active Close**:
   - ESTABLISHED → FIN_WAIT1 → FIN_WAIT2 → TIME_WAIT

3. **Passive Close**:
   - ESTABLISHED → CLOSE_WAIT → LAST_ACK → CLOSED

4. **Simultaneous Close**:
   - FIN_WAIT1 → CLOSING → TIME_WAIT

5. **RST Handling**:
   - ANY state + RST → CLOSED

**Verification Methods**:
- Enable DEBUG_MODE for state transition logging
- Use bpf_printk() to trace state changes
- Monitor eBPF verifier output during load
- Observe kernel logs for state transitions

**Performance Validation**:
- Measure hot path latency (should be < 10ns increase)
- Verify inline compilation (no function calls)
- Check eBPF instruction count within limits

**Compilation Testing**:

```bash
make bpf

# - is_tcp_closing_xdp() in XDP

```
