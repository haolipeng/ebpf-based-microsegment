# Task: eBPF Tracepoint 和进程监控

## Description

实现基于 eBPF tracepoint 的主动进程监控系统，解决短生命周期进程（如 curl）的信息获取问题。通过挂载 `tp/sched/sched_process_exec` tracepoint，在进程创建时立即捕获进程信息（PID、comm、容器ID），并同时维护 eBPF 内核缓存（供 TC/XDP 快速查询）和向用户态发送事件（用于完整路径解析）。

**核心目标**:
- 在进程执行时刻捕获信息（此时进程一定存在）
- 解决路径查询失败问题（进程已退出导致 /proc/<pid> 不存在）
- 从 cgroup 提取容器 ID，支持容器环境流量隔离
- 为 TC/XDP 程序提供低延迟进程信息查询接口（< 2μs）

```c
// process_monitor.h

// eBPF map 存储的进程缓存条目（仅关键信息）
struct process_cache_entry {
    char comm[16];              // Process command name
    __u64 exec_time;            // Process execution timestamp (ns)
    char container_id[64];      // Container ID extracted from cgroup
};

// Ring buffer 发送的进程事件（用户态需要完整信息）
struct process_event {
    __u32 pid;                  // Process ID
    char comm[16];              // Process command name
    __u64 exec_time;            // Execution timestamp
    char container_id[64];      // Container ID
    __u32 flags;                // Reserved for future use
};

// eBPF Maps
struct {
    __uint(type, BPF_MAP_TYPE_LRU_HASH);
    __uint(max_entries, 10000);
    __type(key, __u32);         // PID
    __type(value, struct process_cache_entry);
} process_info_map SEC(".maps");

struct {
    __uint(type, BPF_MAP_TYPE_RINGBUF);
    __uint(max_entries, 256 * 1024);  // 256KB
} process_events SEC(".maps");
```

```c
SEC("tp/sched/sched_process_exec")
int trace_sched_process_exec(struct trace_event_raw_sched_process_exec *ctx)
{
    struct process_event event = {};

    // 1. Get process information
    __u64 pid_tgid = bpf_get_current_pid_tgid();
    event.pid = pid_tgid >> 32;
    event.exec_time = bpf_ktime_get_ns();
    bpf_get_current_comm(&event.comm, sizeof(event.comm));

    // 2. Extract container ID from cgroup path
    extract_container_id_from_cgroup(&event);

    // 3. Cache to eBPF map (for fast lookup by TC/XDP)
    struct process_cache_entry cache_entry = {
        .exec_time = event.exec_time,
    };
    __builtin_memcpy(cache_entry.comm, event.comm, sizeof(cache_entry.comm));
    __builtin_memcpy(cache_entry.container_id, event.container_id, sizeof(cache_entry.container_id));
    bpf_map_update_elem(&process_info_map, &event.pid, &cache_entry, BPF_ANY);

    // 4. Send to userspace (for full path resolution)
    bpf_ringbuf_output(&process_events, &event, sizeof(event), 0);

    return 0;
}
```

### 代码模式

- **使用 BTF CO-RE**: 通过 `vmlinux.h` 和 `BPF_CORE_READ` 宏安全读取内核结构
- **错误处理**: Tracepoint 返回非零值会导致程序卸载，务必返回 0
- **性能优化**: LRU map 自动淘汰，无需手动清理
- **内存安全**: 使用 `__builtin_memcpy` 而非循环赋值（eBPF verifier 友好）
