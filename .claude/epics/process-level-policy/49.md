# Task: FlowCollector 和 PolicyManager 扩展

## Description
扩展 FlowCollector 和 PolicyManager 以支持进程级策略执行。FlowCollector 需要从 flow_event 中解析进程字段并查询 ProcessCache 获取完整信息，PolicyManager 需要支持进程策略的分发和执行。

## Acceptance Criteria
- [ ] FlowCollector 能够从 flow_event 中解析 PID、UID、comm 字段
- [ ] FlowCollector 集成 ProcessCache 查询，获取完整进程信息
- [ ] PolicyManager 支持进程策略的加载和缓存
- [ ] PolicyManager 能够根据进程名称和路径进行策略匹配
- [ ] 流事件包含完整的进程上下文信息
- [ ] 策略执行决策考虑进程级规则

## Technical Details

### FlowCollector 扩展
- **File**: `src/agent/pkg/flow/collector.go`
- Parse process fields from eBPF flow_event:
  - `pid`: Process ID
  - `uid`: User ID
  - `comm`: Process command name (16 bytes)
- Query ProcessCache for enrichment:
  - Full executable path
  - Command line arguments
  - Parent PID
  - Process start time
- Handle cache miss scenarios (process may have exited)

### PolicyManager 扩展
- **File**: `src/agent/pkg/policy/manager.go`
- Add process policy storage:
  ```go
  type ProcessPolicy struct {
      ProcessName string
      ProcessPath string
      Action      PolicyAction
      Priority    int
  }
  ```
- Implement process policy matching logic:
  - Exact match by process name
  - Path prefix match by process path
  - Wildcard support (e.g., "nginx*")
- Policy priority resolution (process > network)
- Cache process policies for fast lookup

### Integration Points
- FlowCollector -> ProcessCache query interface
- FlowCollector -> PolicyManager policy check
- Enhanced flow event structure with process info
- Policy decision logging for audit
