# Task: 安全加固实现

## Description
实现进程安全加固机制，包括进程路径合法性检查、可疑进程识别和安全告警生成。通过分析进程路径和行为特征，识别潜在的安全风险并生成告警。

- [ ] 实现可疑进程识别逻辑（异常路径、临时目录、权限提升）
- [ ] 生成结构化安全告警事件
- [ ] 告警包含详细上下文信息（进程、连接、时间戳）
- [ ] 支持告警级别分类（INFO、WARNING、CRITICAL）

## Technical Details

### Process Path Validation
- **File**: `src/agent/pkg/security/validator.go`
- Implement path legitimacy checks:
  ```go
  type PathValidator struct {
      SystemDirs    []string  // /usr/bin, /usr/sbin, /bin, /sbin
      SuspiciousDirs []string  // /tmp, /dev/shm, /var/tmp
      UserDirs      []string  // /home/*, /root
  }
  ```
- Classification logic:
  - System processes: paths in system directories
  - User processes: paths in user directories
  - Suspicious processes: paths in temporary/writable locations
- Check for path anomalies:
  - Deleted executables (path ends with " (deleted)")
  - Hidden files (starts with ".")
  - Unusual extensions or no extension

### Suspicious Process Detection
- Identify suspicious patterns:
  - Process running from /tmp or /dev/shm
  - Process with elevated privileges (UID 0) from user directory
  - Process name mismatch (comm != basename(path))
  - Known malicious process names (hardcoded blacklist)
- Behavioral analysis:
  - Unexpected network connections from system processes
  - High-privilege processes connecting to unusual ports
  - Processes connecting to known bad IPs (if available)

### Security Alert Generation
- **File**: `src/agent/pkg/security/alert.go`
- Alert structure:
  ```go
  type SecurityAlert struct {
      AlertID     string
      Level       AlertLevel  // INFO, WARNING, CRITICAL
      Type        AlertType   // SUSPICIOUS_PATH, PRIVILEGE_ESCALATION, etc.
      ProcessInfo ProcessInfo
      FlowInfo    FlowEvent
      Reason      string
      Timestamp   time.Time
  }
  ```
- Alert types:
  - `SUSPICIOUS_PATH`: Process from suspicious directory
  - `PRIVILEGE_ESCALATION`: UID 0 process from user directory
  - `NAME_MISMATCH`: Process name doesn't match executable
  - `ANOMALOUS_CONNECTION`: Unexpected network behavior
- Rate limiting to prevent alert flooding
- Send alerts to control plane via gRPC
