# Task: gRPC API 和数据模型扩展

## Description
扩展 gRPC API 定义和数据模型以支持进程级策略和流事件。在 FlowEvent 消息中添加 ProcessInfo 字段，在 Policy 消息中添加进程匹配字段，并更新数据库 schema 以持久化这些信息。

## Acceptance Criteria
- [ ] FlowEvent proto 扩展包含 ProcessInfo 嵌套消息
- [ ] Policy proto 扩展包含 process_name 和 process_path 字段
- [ ] SecurityAlert proto 定义完整（告警类型、级别、上下文）
- [ ] 数据库 schema 更新支持进程策略存储
- [ ] 数据库 schema 更新支持流事件进程信息存储
- [ ] 向后兼容性测试通过（旧版 agent/server 不会崩溃）

## Technical Details

### FlowEvent Proto Extension
- **File**: `api/proto/flow/flow.proto`
- Add ProcessInfo message:
  ```protobuf
  message ProcessInfo {
      uint32 pid = 1;
      uint32 ppid = 2;
      uint32 uid = 3;
      uint32 gid = 4;
      string comm = 5;          // 16-byte process name
      string exe_path = 6;      // Full executable path
      string cmdline = 7;       // Command line arguments
      uint64 start_time = 8;    // Process start timestamp
      bool is_suspicious = 9;   // Marked by security validator
  }

  message FlowEvent {
      // ... existing fields ...
      ProcessInfo process_info = 20;  // Add to existing message
  }
  ```

### Policy Proto Extension
- **File**: `api/proto/policy/policy.proto`
- Extend Policy message:
  ```protobuf
  message Policy {
      // ... existing fields ...
      string process_name = 10;  // Process command name (e.g., "nginx")
      string process_path = 11;  // Process path prefix (e.g., "/usr/bin/")
      ProcessMatchMode match_mode = 12;  // EXACT, PREFIX, WILDCARD
  }

  enum ProcessMatchMode {
      EXACT = 0;      // Exact match on process_name
      PREFIX = 1;     // Prefix match on process_path
      WILDCARD = 2;   // Wildcard match (supports * and ?)
  }
  ```

### SecurityAlert Proto Definition
- **File**: `api/proto/alert/alert.proto` (new file)
- Define alert message:
  ```protobuf
  message SecurityAlert {
      string alert_id = 1;
      AlertLevel level = 2;
      AlertType type = 3;
      ProcessInfo process_info = 4;
      FlowEvent flow_event = 5;
      string reason = 6;
      int64 timestamp = 7;
  }

  enum AlertLevel {
      INFO = 0;
      WARNING = 1;
      CRITICAL = 2;
  }

  enum AlertType {
      SUSPICIOUS_PATH = 0;
      PRIVILEGE_ESCALATION = 1;
      NAME_MISMATCH = 2;
      ANOMALOUS_CONNECTION = 3;
  }
  ```

### Database Schema Updates
- **Files**: SQL migration files in `src/server/migrations/`

- Migration: `000Z_create_security_alerts.up.sql`
  ```sql
  -- Create security alerts table
  CREATE TABLE security_alerts (
      id SERIAL PRIMARY KEY,
      alert_id VARCHAR(64) UNIQUE NOT NULL,
      level INT NOT NULL,
      type INT NOT NULL,
      pid INT,
      exe_path VARCHAR(1024),
      flow_id BIGINT,
      reason TEXT,
      timestamp BIGINT NOT NULL,
      created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  );

  CREATE INDEX idx_alerts_timestamp ON security_alerts(timestamp);
  CREATE INDEX idx_alerts_level ON security_alerts(level);
  ```
