## Technical Details

### Process Policy CRUD API
- **File**: `src/server/internal/api/policy.go`
- RESTful endpoints:
  - `POST /api/v1/policies` - Create process policy
  - `GET /api/v1/policies` - List policies (with filter by process_name/path)
  - `GET /api/v1/policies/:id` - Get specific policy
  - `PUT /api/v1/policies/:id` - Update policy
  - `DELETE /api/v1/policies/:id` - Delete policy
- Request/Response models:
  ```go
  type CreateProcessPolicyRequest struct {
      ProcessName string `json:"process_name" validate:"max=255"`
      ProcessPath string `json:"process_path" validate:"max=1024"`
      MatchMode   string `json:"match_mode" validate:"oneof=exact prefix wildcard"`
      Action      string `json:"action" validate:"oneof=allow deny alert"`
      Priority    int    `json:"priority" validate:"min=0,max=1000"`
      Description string `json:"description" validate:"max=500"`
  }

  type ProcessPolicyResponse struct {
      ID          int       `json:"id"`
      ProcessName string    `json:"process_name"`
      ProcessPath string    `json:"process_path"`
      MatchMode   string    `json:"match_mode"`
      Action      string    `json:"action"`
      Priority    int       `json:"priority"`
      Description string    `json:"description"`
      CreatedAt   time.Time `json:"created_at"`
      UpdatedAt   time.Time `json:"updated_at"`
  }
  ```

### Policy Validation
- Validation rules:
  - `process_name`: Max 255 chars, alphanumeric + "_-."
  - `process_path`: Max 1024 chars, valid Unix path format
  - `match_mode`: Must be one of: exact, prefix, wildcard
  - `action`: Must be one of: allow, deny, alert
  - `priority`: 0-1000 range
- Path legitimacy checks:
  - Must be absolute path (starts with "/")
  - Cannot contain "../" or suspicious patterns
  - Warn if path is in temporary/writable directories
- Conflict detection:
  - Check for duplicate policies (same process_name + process_path)
  - Warn if overlapping policies with different actions
  - Validate priority ordering
- Error responses:
  ```go
  type ValidationError struct {
      Field   string `json:"field"`
      Message string `json:"message"`
      Value   string `json:"value"`
  }
  ```

### Security Alert API
- **File**: `src/server/internal/api/alert.go`
- RESTful endpoints:
  - `GET /api/v1/alerts` - List security alerts (paginated)
  - `GET /api/v1/alerts/:id` - Get specific alert details
  - `PUT /api/v1/alerts/:id/acknowledge` - Acknowledge alert
  - `GET /api/v1/alerts/stats` - Get alert statistics
- Query parameters:
  - `level`: Filter by alert level (info/warning/critical)
  - `type`: Filter by alert type
  - `start_time`: Filter by time range (start)
  - `end_time`: Filter by time range (end)
  - `process_path`: Filter by process path
  - `page`: Page number (default: 1)
  - `page_size`: Items per page (default: 50, max: 100)
- Response model:
  ```go
  type AlertListResponse struct {
      Alerts     []SecurityAlertResponse `json:"alerts"`
      TotalCount int                     `json:"total_count"`
      Page       int                     `json:"page"`
      PageSize   int                     `json:"page_size"`
  }

  type SecurityAlertResponse struct {
      AlertID     string    `json:"alert_id"`
      Level       string    `json:"level"`
      Type        string    `json:"type"`
      ProcessInfo struct {
          PID     int    `json:"pid"`
          ExePath string `json:"exe_path"`
          Cmdline string `json:"cmdline"`
      } `json:"process_info"`
      FlowInfo struct {
          SrcIP   string `json:"src_ip"`
          DstIP   string `json:"dst_ip"`
          DstPort int    `json:"dst_port"`
      } `json:"flow_info"`
      Reason       string    `json:"reason"`
      Timestamp    time.Time `json:"timestamp"`
      Acknowledged bool      `json:"acknowledged"`
  }
  ```

### Alert Statistics API
- Aggregate statistics:
  - Count by alert level (last 24h, 7d, 30d)
  - Count by alert type (last 24h, 7d, 30d)
  - Top suspicious processes (by alert count)
  - Timeline data for charting (hourly/daily buckets)
- Response model:
  ```go
  type AlertStatsResponse struct {
      ByLevel    map[string]int      `json:"by_level"`     // "critical": 5
      ByType     map[string]int      `json:"by_type"`      // "suspicious_path": 10
      TopProcess []ProcessAlertCount `json:"top_processes"`
      Timeline   []TimelineBucket    `json:"timeline"`
  }
  ```

### gRPC Service Implementation
- **File**: `src/server/internal/grpc/policy_service.go`
- Implement PolicyService gRPC interface:
  - `CreatePolicy(CreatePolicyRequest) returns (PolicyResponse)`
  - `GetPolicy(GetPolicyRequest) returns (PolicyResponse)`
  - `ListPolicies(ListPoliciesRequest) returns (ListPoliciesResponse)`
  - `UpdatePolicy(UpdatePolicyRequest) returns (PolicyResponse)`
  - `DeletePolicy(DeletePolicyRequest) returns (Empty)`
- Used by agents to fetch policies on startup/reload

### Authorization and Audit
- Role-based access control (RBAC):
  - Admin: Full access to all APIs
  - Operator: Read all, write policies
  - Viewer: Read-only access
- Audit logging:
  - Log all policy modifications (who, what, when)
  - Log sensitive alert acknowledgments
  - Store in database for compliance
