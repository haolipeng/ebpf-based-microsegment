# Task: Dashboard 进程可见性

## Description
Implement process-level visibility in the Flow Dashboard to display process information alongside network flows. This task enhances the existing flow list component to show process metadata (name, path, container ID) extracted from eBPF programs, enabling administrators to understand which processes are generating network traffic.

The implementation extends the current flow display with additional columns for process information, adds filtering/search capabilities for process-based queries, and provides statistical charts showing process-level network activity patterns.

## Acceptance Criteria
- [ ] Flow list displays process columns: Process Name, Process Path, Container ID
- [ ] Process filtering functionality works (filter by name, path, or container ID)
- [ ] Process search bar enables quick lookup of specific processes
- [ ] Process statistics charts show: Top processes by bandwidth, Connection count per process, Process distribution by container
- [ ] UI handles missing process information gracefully (e.g., kernel processes)
- [ ] Column sorting works for all process fields
- [ ] Responsive design maintains usability on different screen sizes

## Technical Details
Enhance the Flow Dashboard with process-level data visualization:

**Key files to create/modify:**
- `web/src/components/FlowList.tsx` - Add process columns to flow table
- `web/src/components/ProcessStats.tsx` - Create process statistics component
- `web/src/types/flow.ts` - Extend flow type with process fields
- `web/src/hooks/useProcessFilter.ts` - Process filtering logic

**Data structures involved:**
```typescript
interface ProcessInfo {
  name: string;          // From task_comm
  path: string;          // From exe_path
  containerId: string;   // From container_id
  pid: number;
  startTime: number;
}

interface FlowWithProcess extends Flow {
  process: ProcessInfo | null;
}
```

**Code patterns to follow:**
- Use React Table library for sortable/filterable columns
- Implement debounced search for performance
- Use Chart.js or Recharts for process statistics visualization
- Handle null process data with clear UI indicators
- Leverage existing flow data fetching infrastructure
