# Task: 安全告警面板

## Description
Implement a Security Alerts Panel in the dashboard to display suspicious process activity detected by the eBPF-based monitoring system. This panel provides real-time visibility into potential security threats, showing processes that violate policies or exhibit anomalous behavior, and enables administrators to quickly respond with one-click blocking actions.

The panel presents a prioritized list of security events with context (process details, violation type, timestamp) and integrates with the policy enforcement engine to allow immediate mitigation.

## Acceptance Criteria
- [ ] Suspicious process list displays: Process name/path, Violation type (unauthorized connection, spoofing detected, etc.), Timestamp, Severity level (Critical/High/Medium/Low), Container ID (if applicable)
- [ ] Alert count displayed prominently with severity breakdown
- [ ] Real-time notifications for new high-severity alerts
- [ ] One-click "Block Process" button for immediate policy creation
- [ ] Alert detail view shows full context (source/dest IPs, ports, policy matched)
- [ ] Alert filtering by severity, violation type, and time range
- [ ] Alert acknowledgment and dismissal functionality

## Technical Details
Create a dedicated security alerts component with real-time updates and action capabilities:

**Key files to create/modify:**
- `web/src/components/SecurityAlerts.tsx` - Main alert panel component
- `web/src/components/AlertDetail.tsx` - Detailed alert view modal
- `web/src/hooks/useSecurityAlerts.ts` - Alert data fetching and WebSocket subscription
- `web/src/types/alert.ts` - Alert type definitions
- `web/src/services/alertService.ts` - Alert API calls and block actions

**Data structures involved:**
```typescript
interface SecurityAlert {
  id: string;
  timestamp: number;
  severity: 'critical' | 'high' | 'medium' | 'low';
  violationType: 'unauthorized_connection' | 'path_spoofing' | 'policy_violation';
  process: ProcessInfo;
  network: {
    srcIp: string;
    dstIp: string;
    srcPort: number;
    dstPort: number;
    protocol: string;
  };
  policyMatched?: string;
  acknowledged: boolean;
}
```

**Code patterns to follow:**
- Use WebSocket or Server-Sent Events for real-time alert updates
- Implement notification API integration for browser notifications
- Use color coding for severity levels (red/orange/yellow/blue)
- Debounce block action to prevent accidental clicks
- Show confirmation dialog before blocking critical system processes
- Log all block actions for audit trail
