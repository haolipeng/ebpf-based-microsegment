# LPM Trie eBPF 数据结构与 Map 定义

## 描述

定义 LPM Trie 所需的数据结构(lpm_key, lpm_value, policy_detail)和 eBPF Maps,为 LPM 查找逻辑提供基础数据结构支持。

## 受影响的文件

- `src/bpf/headers/common_types.h` (修改)
- `src/bpf/headers/policy_match_lpm.h` (新文件)

## 验收标准

- [ ] 定义 lpm_key 结构(prefixlen + ip)
- [ ] 定义 lpm_value 结构(rule_ids[8] + rule_count)
- [ ] 定义 policy_detail 结构
- [ ] 创建 src_ip_lpm_map, dst_ip_lpm_map (BPF_MAP_TYPE_LPM_TRIE)
- [ ] 创建 policy_detail_map (BPF_MAP_TYPE_HASH)
- [ ] eBPF verifier 验证通过

## 实现细节

### LPM Key 结构
```c
struct lpm_key {
    __u32 prefixlen;    // prefix length in bits
    __u32 ip;           // IPv4 address in network byte order
};
```

### LPM Value 结构
```c
struct lpm_value {
    __u32 rule_ids[8];  // up to 8 matching rules
    __u32 rule_count;   // actual number of rules
};
```

### Policy Detail 结构
```c
struct policy_detail {
    __u16 dst_port_start;
    __u16 dst_port_end;
    __u8 protocol;      // IPPROTO_TCP, IPPROTO_UDP, etc.
    __u8 direction;     // ingress=1, egress=2
    __u8 action;        // allow=1, deny=2
    __u8 reserved;
    __u32 priority;
};
```

### eBPF Maps
- `src_ip_lpm_map`: BPF_MAP_TYPE_LPM_TRIE for source IP prefix matching
- `dst_ip_lpm_map`: BPF_MAP_TYPE_LPM_TRIE for destination IP prefix matching
- `policy_detail_map`: BPF_MAP_TYPE_HASH for policy metadata storage
