# eBPF LPM 查找逻辑实现

## 描述

实现 `lookup_policy_action_lpm()` 函数,使用 LPM Trie 进行高效的策略匹配。该函数通过源 IP 和目标 IP 的前缀匹配,结合候选集合求交集,实现快速的多维策略查询。

## 受影响的文件

- `src/bpf/headers/policy_match_lpm.h`

## 验收标准

- [ ] 实现 LPM 查找流程(src_ip + dst_ip)
- [ ] 实现候选集合求交集逻辑
- [ ] 实现细粒度过滤(port, protocol, direction)
- [ ] 实现优先级比较
- [ ] TC 和 XDP 程序集成
- [ ] eBPF verifier 验证通过
- [ ] 单元测试覆盖核心逻辑

## 实现细节

### LPM 查找流程

1. 使用源 IP 在 `src_ip_lpm_map` 中查找,获取匹配的 rule_ids 集合
2. 使用目标 IP 在 `dst_ip_lpm_map` 中查找,获取匹配的 rule_ids 集合
3. 对两个集合求交集,得到候选规则列表
4. 遍历候选规则,进行细粒度过滤(port, protocol, direction)
5. 在满足条件的规则中选择优先级最高的规则

### 关键函数

```c
// LPM lookup with intersection
static inline __u32 lookup_policy_action_lpm(
    struct packet_context *ctx,
    __u32 src_ip,
    __u32 dst_ip,
    __u16 dst_port,
    __u8 protocol,
    __u8 direction
);
```

### 集合求交集算法

使用位运算或线性扫描方式,实现两个候选集合的交集计算。

### 细粒度过滤

匹配规则的 port, protocol, direction 字段,逐一检查候选规则是否满足条件。
