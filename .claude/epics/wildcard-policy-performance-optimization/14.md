# Server 端 LPM 管理 API 开发

## 描述

实现 `WildcardPolicyManager`,支持 LPM Trie 的策略 CRUD 操作。该管理器负责策略的加载、删除、更新等操作,并支持从数组形式迁移到 LPM Trie 形式的策略管理。

## 实现细节

### WildcardPolicyManager 接口

```go
type WildcardPolicyManager interface {
    // Add a new policy, automatically choose Array or LPM strategy
    AddPolicy(ctx context.Context, policy *Policy) error

    // Delete a policy by ID
    DeletePolicy(ctx context.Context, policyID string) error

    // List all policies
    ListPolicies(ctx context.Context) ([]*Policy, error)

    // Migrate policies from Array to LPM Trie
    MigrateToLPM(ctx context.Context, policyIDs []string) error

    // Check if LPM is enabled
    IsLPMEnabled() bool
}
```

### 关键特性

1. **自动策略选择**: 根据 CIDR 覆盖率、规则数量等因素,自动选择 Array 或 LPM Trie 策略
2. **Feature Flag 支持**: 通过配置开关支持 LPM 的启用/禁用
3. **CIDR 解析**: 将 CIDR 字符串转换为 LPM key (prefixlen + IP)
4. **迁移工具**: 支持从 Array 形式迁移到 LPM Trie 形式

### CIDR 转换函数

```go
// Convert CIDR string to LPM key
func cidrToLPMKey(cidr string) (*LPMKey, error)

// Convert IP network to LPM value
func networkToLPMValue(net *net.IPNet) (*LPMValue, error)
```

### Feature Flag 配置

```go
type Config struct {
    UseLPM          bool
    LPMThreshold    int    // minimum rule count to use LPM
    ArrayThreshold  int    // maximum CIDR count for array-based matching
}
```
