### [核心概念](concepts.md)

理解系统的关键概念：

- **策略 (Policy)**: 定义流量允许/拒绝规则
- **会话 (Session)**: 连接状态追踪
- **事件 (Event)**: 系统产生的各类事件
- **工作负载 (Workload)**: 被监控的容器/进程

## 系统要求

### 硬件要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 2 核 | 4 核+ |
| 内存 | 2 GB | 4 GB+ |
| 磁盘 | 10 GB | 50 GB+ |

### 软件要求

| 组件 | 版本要求 |
|------|----------|
| Linux 内核 | 5.4+ (推荐 5.10+) |
| Go | 1.21+ |
| Clang/LLVM | 14+ |

### 支持的平台

- Ubuntu 20.04/22.04 LTS
- Debian 11/12
- CentOS/RHEL 8/9
- Kubernetes 1.24+
