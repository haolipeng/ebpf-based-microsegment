# 提案：Web UI Agent 管理页面

**Change ID**: `add-web-ui-agent-management`
**创建时间**: 2025-11-07
**状态**: 提案
**优先级**: P1 (高优先级 - 核心功能)
**预计工作量**: 1-2 天

---

## 为什么 (Why)

运维人员需要详细的 Agent 管理界面来监控和管理所有已注册的 Agent。

**当前痛点**:
- Dashboard 只显示 Agent 概览(在线/离线数量)
- 无法查看每个 Agent 的详细信息
- 无法快速定位有问题的 Agent
- 无法查看 Agent 的历史数据和指标趋势

**业务需求**:
- 查看所有 Agent 的列表和状态
- 筛选和搜索 Agent (按主机名、IP、状态)
- 查看 Agent 详细信息(指标、配置、流量统计)
- 监控 Agent 健康状况和心跳
- 识别离线或异常的 Agent

---

## 变更内容 (What Changes)

实现 Agent 管理页面,提供完整的 Agent 监控和管理功能。

### 1. Agent 列表页面
- **表格展示**: 使用 Ant Design Table 组件
  - 显示字段: ID、主机名、IP 地址、版本、状态、最后心跳时间
  - 状态徽章: 在线(绿色)、离线(灰色)、错误(红色)
  - 排序功能: 支持按各列排序
  - 分页: 支持大量 Agent 展示

- **搜索和筛选**:
  - 搜索框: 按主机名或 IP 地址搜索
  - 状态筛选: 仅显示在线/离线/错误状态
  - 实时刷新: 每 30 秒自动刷新

- **操作列**:
  - 查看详情按钮
  - 快速操作菜单(未来扩展: 重启、删除等)

### 2. Agent 详情页面
- **基本信息卡片**:
  - Agent ID、主机名、IP 地址
  - 版本信息、启动时间
  - 当前状态、最后心跳时间

- **性能指标卡片**:
  - CPU 使用率 (百分比进度条)
  - 内存使用量 (格式化显示)
  - 已上报流数量
  - 生效策略数量
  - 处理/丢弃包数(如果可用)

- **流量统计图表**:
  - 流上报趋势图 (时间序列)
  - 包处理趋势图

- **心跳历史**:
  - 最近心跳时间列表
  - 离线时段标记

### 3. 状态监控
- **健康检查**:
  - Agent 心跳超时检测
  - 异常状态告警(红色标记)

- **自动刷新**:
  - 列表页面每 30 秒刷新
  - 详情页面每 10 秒刷新
