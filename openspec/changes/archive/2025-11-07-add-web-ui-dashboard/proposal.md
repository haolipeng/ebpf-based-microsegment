# 提案：Web UI Dashboard 仪表板

**Change ID**: `add-web-ui-dashboard`
**创建时间**: 2025-11-07
**状态**: 提案
**优先级**: P1 (高优先级 - 核心功能)
**预计工作量**: 2-3 天

---

## 为什么

运维人员需要一个统一的概览页面来快速了解系统整体状态。

**当前痛点**:
- 无法一眼看出有多少 Agent 在线
- 无法快速查看流量趋势
- 无法看到策略应用情况
- 需要分别查看多个页面才能了解系统状态

**业务需求**:
- 提供系统关键指标概览
- 实时展示流量趋势
- 显示 Top Talkers
- 快速发现异常和问题

## 变更内容

实现Dashboard 仪表板页面,提供系统全局视图。

### 1. 关键指标卡片
- **活跃 Agent 数**: 显示在线/总数
- **总流量**: 实时更新的字节数/包数
- **策略数量**: 生效中的策略规则数
- **告警数**: 最近告警数量(未来扩展)

### 2. 流量趋势图
- **时间序列图表**: 最近 1 小时/6 小时/24 小时流量
- **协议分布**: TCP/UDP/ICMP 占比
- **策略动作分布**: ALLOW/DENY/LOG 统计

### 3. Top Talkers
- **Top 10 源 IP**: 按流量字节数排序
- **Top 10 目标 IP**: 按流量字节数排序
- **实时更新**: 每 30 秒刷新

### 4. 最近事件
- **Agent 上线/下线事件**
- **策略变更事件**
- **流量异常事件**(未来扩展)

### 5. 系统状态
- **API 连接状态**: 后端连接健康度
- **WebSocket 状态**: 实时流连接状态
- **数据刷新时间**: 最后更新时间戳

---

- [ ] 流量趋势图渲染正常,支持时间范围切换
- [ ] Top Talkers 列表正确显示并自动刷新
- [ ] 数据自动刷新(每 30-60 秒)
- [ ] Loading 状态友好
- [ ] 错误处理完善(API 失败时显示提示)

---

## 依赖

- 需要完成 Web UI 基础架构(add-web-ui-foundation)
- 需要后端 API:
  - `GET /api/v1/agents` - Agent 列表
  - `GET /api/v1/flows/summary` - Flow 统计
  - `GET /api/v1/policies` - Policy 列表
  - `GET /api/v1/aggregator/top-talkers` - Top Talkers

**包含范围**:
- Dashboard 页面组件
